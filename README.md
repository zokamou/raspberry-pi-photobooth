# Raspberry Pi Photobooth

## Description
Photobooth using Raspberry Pi 5, a camera, a touch screen, and a thermal printer. This project was inspired by someone I had seen on social media, and it looked like a fun way to dive into a field I was less experienced in. I have mainly dealt with software, but have had some small experience with Arduino and Raspberry Pis in the past. Hardware has always interested me, and its beginning to turn into a hobby of mine!

## Hardware used
* Raspberry Pi 5
* Hosyond 7" touch screen display
* 1080p HD OV5647 camera module
* 58mm ESC/POS thermal receipt printer

## Product Features
* Customizable home screen (this was a big one for me, as I was inspired to build this for different events!)
* Camera display with countdown timer
* Auto-print after capture using the thermal receipt printer
